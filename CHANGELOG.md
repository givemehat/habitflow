# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-08

### Added
- **SwiftData Storage**: Offline-first, fast, local-only database for habits and completion history logs.
- **Interactive Widgets**: Support for Small, Medium, and Large widgets with AppIntents for checking off habits directly from the Desktop/Notification Center.
- **Heatmap View**: GitHub-style contribution heatmap with customizable Month and Year grids, color intensity, and hover tooltips.
- **Local Analytics**: Weekly, monthly, and yearly progress charts (built using Apple Charts), active streaks tracker, and custom category distributions.
- **Offline Insight Engine**: Intelligently calculates completion biases (e.g. weekday vs weekend completions, peak days, evening drops) 100% locally.
- **Import/Export Suite**: Automated/manual JSON database backups, CSV data tables generator, and printable vector PDF progress report.
- **Accessibility & Shortcuts**: Full VoiceOver labels, keyboard navigation focus controls (⌘N, ⌘E, ⌘F, ⌘,), and Spacebar completion checkoffs.
- **Multiple Schedules**: Support for Daily, Weekly target counts, Alternate Days, and Custom Weekdays goal styles.
- **Widget Styling Themes**: Minimal, Glass, Monochrome, GitHub Style, and Apple Notes themes.
