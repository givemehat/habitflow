# Security Policy

## Privacy & Security Stance

HabitFlow is a **privacy-first** application. All data, settings, logs, and statistics are stored locally on your device within Apple's secure sandboxed container.

- **No Analytics Tracking**: HabitFlow does not include any third-party SDKs, telemetry, or analytics tracking.
- **No Network Calls**: The app does not communicate with external servers. Everything works 100% offline.
- **No Account Creation**: No username, email, or credentials are required.

## Reporting a Security Vulnerability

If you discover a potential security vulnerability, please report it immediately by opening a confidential discussion or email to the repository maintainer. 

We ask you to report issues responsibly and allow us time to investigate and fix any vulnerabilities before disclosing them publicly.
